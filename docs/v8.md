# v8

本文件是 0.8.0（v8）的产品范围和开发计划。v1 到 v7 的产品面与验收不变，只有两条例外：`Input` 的 `onChange` 不再收到字符串，改为收到 `{ value }`；下面点名的无载荷事件改为零参数调用。v8 不从「以后要做」取项，不新增能力。没列出的仍留在原档。永久不做、不预承诺不因 v8 改变。

## 目标

nsh 在 `ca59368b` 之后把「每个事件一个对象；没有要报告的就不传参」定成公开形状（`nsh-js` 的 `host.rs` 把 `onChange` 写成 `{ value }`；规则在 nsh `docs/dev/api-naming.md` 的 Payloads）。抽代码的起点在这之前。

截图里其余几条，nlayer 已经是那个形状，或者功能还没做。v8 只改已经在跑、形状还不对的调用。

## 完成的标准

同一个 TSX 应用用 v8 的 CLI 在三端跑起来，并满足：

1. `onChange` 收到 `{ value: string }`。`value` 是输入框里现在的整段文本，单行和 `multiline` 一样。字符串不再传入。`onChange={signal.set}` 不成立：`set` 会收到这个对象，不是文本。
2. 无载荷事件零参数调用：`onPress`、`onLongPress`、`onRefresh`、`onLoadMore`、`onBackPress`、`onDismiss`、`onShow`、`onClose`。QuickJS 不再传 `{}`，web 不再传 `null`。
3. 其余事件的载荷不变。`onSelectionChange({ start, end })`、`onCompositionChange({ composing, text })`、滚动六事件的 `{ offset, contentSize, size }`、手势、`onViewableItemsChange`、`onRequestClose({ reason })`、`onInsets` 保持现在的对象。
4. `EventPayload::None` 不按变体一刀切。Android 的 `onPanStart`、`onPinchStart`、`onRotationStart` 仍用 `None` 占位，类型要的是对象，继续走现在的对象路径，不改成零参数。`onViewableItemsChange` 在没有范围时同样保持现在的空载荷，不改成零参数。
5. 类型、`examples/gallery`、仓库里的 TSX 调用处一起改。`nlayer test` 的 `type(selector, text)` 仍传入文本：无窗口按协议逐次 `Change`，`--target` 走平台键盘。应用侧 handler 收到对象。不新增测试 API，不新增 crate，不新增公开模块，不改 `nlayer.json`。
6. 测试：无窗口断言 `onChange` 的参数是 `{ value }` 而不是字符串，并断言 `onPress` 的参数个数是 0。web 的运行时测试断言同一形状（`{ value }`，无载荷不传参）。不新开一屏。不做设备像素断言。

## 产品面

### `onChange`

字段名是 prop 的名字 `value`，和 nsh 的 `onChange({ value })` 一致。只有这一个字段。受控 `value` 仍是字符串。

QuickJS 和 web 同一形状。web 现在把文本编成字符串再交给页面里的 handler；v8 编成 `{ value }`。

### 无载荷

类型本来就是 `() => void`。实现跟类型对齐：`JS_Call` 的 argc 为 0；页面里的 `event()` 不传第三个参数。

只限完成标准 2 列出的事件。解构一个没传来的参数会抛，所以不能把所有 `None` 都改成零参数。

`onDismiss` 和 `onClose` 都是 `EventKind::Dismiss`，一次改动盖住两个名字。

### 已经对齐，这版不动

- 样式：`boxShadow`、`numberOfLines`、`textOverflow`、`userSelect`、`objectFit` 已经是 style。不恢复 `shadowColor` / `shadowOffset` / `shadowOpacity`、`resizeMode`、`ellipsizeMode`，也不把 `selectable` 从 `View` 的属性挪进样式。`textShadow` 仍只解析，不画。
- 滚动：六事件仍是 v1 的 `{ offset, contentSize, size }`。不收成只有 `offset`，不加 `zoomScale`。
- `onSelectionChange`、`onCompositionChange`、`onRequestClose`、手势事件已经是一个对象，字段名不变。

## 公开模块

不变。只有 `@nlayer/runtime` 和 `@nlayer/ui`。`Input` 的 `onChange` 类型换成 `(e: { value: string }) => void`。类型仍由 `nlayer-bundler` 的 `gen-types` 从 `types.rs` 生成到 `packages/`。

## 开发计划

一个切片。两处派发一起改，否则 web 和 QuickJS 形状不同。行为能跑，测试是绿的。改到的 crate 跑 `cargo test -p`；这一刀动到 TSX 和引擎，`nlayer test` 要绿。

### M1 载荷

- `nlayer-js` 的 `dom::dispatch`：`Change` 的文本做成 `{ value }`。完成标准 2 的事件 `JS_Call` argc 为 0，不分配空对象。
- `nlayer-platform-web`：`Text` 编成 `{ value }`。`runtime.js` 的 `event()` 在无载荷时不传参。`None` 仍编成 `null` 给不在名单里的事件，避免手势开始事件丢参数。
- `types.rs` 的 `onChange`，然后 `gen-types`。
- `examples/gallery`、`nlayer-cli` 的 fixture、测试里的 `(value) =>` / `(text) =>` 改成 `({ value }) =>`。
- `reactive.rs` 里把 `onChange={value.set}` 当成可用写法的注释删掉。`signal.set` 未绑定仍能调用，测试留着，只是不再作为 `onChange` 的写法。

来源：`nsh-js/src/host.rs` 里 `ChangeText` 写成 `{ value }` 的那一段。零参数是 nsh `docs/dev/api-naming.md` 的「没有要报告的就不传参」，不搬 `PressEvent`。

### 顺序

只有 M1。

## 不进 v8

| 项 | 为什么 |
|---|---|
| `pointerEvents`（含 `box-none` / `box-only`） | 没有这个样式键，也没有命中测试。截图里的能力还没做 |
| `onLayout({ bounds })` | 没有 `onLayout` |
| `Image` 的 `onLoad({ size })`、`onContentSizeChange({ size })` | v1 / v2 明确不做。不借改形状把它们加进来 |
| `onMouseEnter` / `onMouseMove` / `onMouseLeave` | 没有这些事件。`hoverStyle` 不是它们 |
| `onPress` 的 `PressEvent`（坐标、修饰键、点击次数） | 三端没有这份数据。nsh 后来总是传它；这里传空对象假装有坐标，比不传更差 |
| 滚动事件收成只有 `{ offset }`，或加上 `zoomScale` | 现在六事件已经是对象，而且比 nsh 的结束事件多 `contentSize` 和 `size`。收窄是丢字段。缩放没做 |
| `textShadow` 的绘制 | v7 已排除。解析留下，不画 |
| `Checkbox`、`Popover` 以及 nsh 0.4.0 的其它组件 | 没有这些组件 |
| `BackHandler.addEventListener` 改成 `on(event, listener)`、按元素拆 ref、调用失败的稳定 `code` | 不是这次选定的形状。现有写法继续有效 |
| 运行时同时接受字符串和 `{ value }` | 公开契约只留一种。双认把旧形状留在运行时 |
| 设备像素断言 | 仍不做 |

## 风险与决定

- **硬切。** 旧的 `(value: string)` 和 `onChange={name.set}` 会在运行时拿到对象，受控值变成对象，输入框跟丢。不提供兼容重载。gallery 和测试在同一切片里改完。
- **无载荷从 `{}`（QuickJS）和 `null`（web）改成没有参数。** `(e) => e` 从对象或 `null` 变成 `undefined`。类型早已是零参数。只限点名的事件；手势开始不在此列，避免 `({ translation }) =>` 在 Android 上抛。
- **不补按压坐标。** 零参数留下以后再加一个对象的位置，和 nsh 那句「没有内容的事件以后可以再加对象」一致。这版不加。
- **两处派发必须同一切片。** 只改 QuickJS 时，`nlayer test --target web` 仍把字符串和 `null` 交给页面。
