# v1

这份文件是 v1 的产品范围。和它冲突的实现改实现，或先改这份文件。不写做到哪了。不做的事在 `AGENTS.md`；本文件不能把那边禁止的东西写成 v1。

## 完成的标准

同一个 TSX 应用，用 `nlayer init` / `build` / `run --target web|ios|android` 在三端跑起来。`nlayer test` 默认在无窗口引擎里跑 TSX，断言 mount 树、文本和布局。`nlayer test --target web|ios|android` 用同一套步骤在对应宿主上操作应用。验收屏至少覆盖：纵向布局、一段 grid、嵌套 `Text` span、打包图片、双轴 `Scroll`、滚动事件回调、`activeStyle` / `hoverStyle` / `focusStyle`、单行受控 `Input`、`onPress`、一处静态 transform、一次 `fetch` JSON、safe area 的 `env()`、`platform.os`。

## 产品面

- 宿主：`View`、`Text`、`Image`、`Scroll`、`Input`。`onPress`。`testID`：测试用来点名视图的字符串，平台不绘制。嵌套 `Text` 的 `testID` 标在该 span 上，测试按它点名这段 span。无障碍 API 以后要做，`testID` 不是它。`If` / `Each`。图：`signal`、`computed`、`effect`、`batch`、`untracked`、`cleanup`、`context`，外加 `ErrorBoundary`。v1 无 `resource`（以后要做，不留）。函数名沿用 nsh，不是 `createSignal`。
- 文本：嵌套 `Text` 是同一段的 span（颜色、字重、字号、斜体），继承父级文本样式。
- 输入：单行受控 `value` / `onChange` / `placeholder` / `disabled`，加 `secureTextEntry` 和 `keyboardType`（`text` / `email` / `number` / `phone`）。`text` / `email` 的 Return 收起键盘；`number` / `phone` 没有 Return。`Keyboard.dismiss()` 收起当前键盘，不看 inset 是否大于 0。
- 样式：Taffy。未写 `display` 为纵向 flex，`flexShrink` 为 0，无 `min-width: auto`。样式 key 以引擎认识的为准（`styles.d.ts`），不另设拒绝白名单。不认识的名字在终端警告且不生效。宿主绘制盒模型、flex、relative/absolute、尺寸、margin/padding（含 `env()` 和 `max(env(a), env(b))`）、纯色背景、border、radius、opacity、overflow、zIndex、列出的文本样式、`objectFit`、静态 transform（`transform` / `translate` / `rotate` / `scale` / `transformOrigin`）、grid（`display: "grid"`、`gridTemplateColumns` / `gridTemplateRows`、`gridAutoColumns` / `gridAutoRows`、`gridAutoFlow`、`gridColumn` / `gridRow` 及其 `Start` / `End`，含 line names）。`activeStyle` / `hoverStyle` / `focusStyle` 进协议，由平台应用。阴影、渐变等残留字段引擎可解析，宿主不画。`class` / `classList` 并进同一套样式 IR。解析器为空，任何 class 在终端警告且不生效，不拆引擎。警告不失败构建。
- 滚动：原生。每实例一轴，横竖各一个 Scroll。`onScroll`、`onScrollEnd`、`onScrollDragStart`、`onScrollDragEnd`、`onMomentumStart`、`onMomentumEnd` 的载荷是 `{ offset: { x, y }, contentSize: { width, height }, size: { width, height } }`，单位是 point。`offset` 是内容偏移，iOS 回弹可以是负数。`contentSize` 是内容尺寸，`size` 是滚动视图的可见区。`onScroll` 至多每帧一次。键盘弹出后，点最近一层 `Scroll` 的空白处收起键盘。`keyboardShouldPersistTaps` 默认 `never`：那一下只收键盘，不触发 `onPress`；`always` 不收；`handled` 只在点到的不是 `onPress` 或输入时收。点在输入上不收。`keyboardDismissMode` 默认 `none`；`on-drag` 与 `interactive` 都在拖过平台阈值时收起，不做跟手动画。inset 为 0 时点按和拖动都不收。v1 无刷新、缩放、分页（以后要做，不留）。
- 图片：打包 `import` 加 `http(s)`。v1 是 PNG / JPEG / WebP（SVG、GIF 以后要做）。系统字体（自定义字体不预承诺）。
- 平台 API：`console`、timers、`queueMicrotask`、`URL` / `URLSearchParams`、`TextEncoder` / `TextDecoder`、`AbortController`、`atob` / `btoa`、`performance.now`、`crypto.getRandomValues`、`fetch` / `Request` / `Response` / `Headers`。body 只有 text / json / arrayBuffer / blob。`Blob` 只作为这个结果类型。`crypto.subtle` 在 QuickJS 宿主（iOS、Android、无窗口 `nlayer test`）是缺的，不是空桩（以后要做）。`fetch` 任意 URL，跟随重定向，认 `AbortSignal`。v1 不带 cookie（以后要做）。无 capability grant（永久）。QuickJS 宿主（iOS、Android、`nlayer test`）由引擎发请求。Web 上应用在页面里跑，`fetch` 就是浏览器的，不进 wasm。页面上的浏览器全局原样可用，v1 不遮蔽；清单以外的浏览器 API 不属于 v1，也不进类型。
- UI 环境留在 `@nlayer/ui`：`platform.os` 为 `web` | `ios` | `android`，safe area，keyboard inset。只通过 `env()` 进入 padding/margin。两个已知变量可以写成 `max(env(a), env(b))`；固定长度仍用 `calc` 加在外面。
- 运行：iOS、Android 和无窗口的 `nlayer test` 用 QuickJS。Web（含 `nlayer test --target web`）不把 QuickJS 打进 wasm：页面执行应用的 ES module，wasm 只跑 reactive 图、布局和 mount batch，DOM 由页面挂。应用的 `fetch` 留在页面，不经引擎。引擎线程产出 batch，平台主线程挂原生视图。`run` 监视 TSX 和资源，重建后重启引擎，状态丢掉。编译失败只打在终端，上一份成功的引擎继续跑。v1 无 HMR（以后要做）；监视重建、重启、丢状态仍是 v1。
- 测试：`*.test.tsx` 导入 `@nlayer/test`，应用 bundle 不能导入。`test`、`expect`、`open`。默认无窗口引擎，文本度量用确定性替身。`nlayer test --target web|ios|android` 把 `open` 的应用跑在该宿主上：web 是无头浏览器，页面执行应用；ios 是模拟器；android 是模拟器或已连接设备。同一套步骤走平台自己的输入，不把事件灌进引擎。断言读宿主挂上的树（文本、输入值、frame），不跟无窗口的度量对齐，也不对齐设备像素。做不到的步骤失败，不退回无窗口。给的是应用入口而不是测试文件时，打开它并执行标准输入里的步骤，`--target` 同样适用。像素对齐断言以后要做。选择器：`id:<testID>`、`text:<文本>`（文本内容、输入的值，空输入还有 placeholder；两端空白去掉后相等），或不带前缀（先 `testID`，再那段文本）。` >> ` 在前一个匹配里面找，`nth=<n>` 从 0 取第 n 个。零个或多于一个匹配则失败。`press` 点匹配本身；它不接 `onPress` 时点最近的可按祖先。点在匹配的中心，嵌套 span 点在该 span 上，由宿主做命中测试。匹配不在可见区域内则失败。`type(selector, text)` 先聚焦该单行输入，再输入 `text`：无窗口按协议逐次 `Change`，`--target` 走该平台键盘，不把整串直接写进引擎。`scroll(selector, distance)` 沿该滚动轴、朝内容末端为正，单位是 point：无窗口改偏移，`--target` 走该宿主的滚动输入（原生滚动视图，或 web 的滚轮）。另有 `waitFor`、`texts`、`inputs`、`tree`、`close`。`open` 的 viewport、safe area、keyboard inset 在 `--target` 上钉住这次运行。
- 底线：iOS 15+，Android API 28+。`run` 用模拟器或浏览器，不重装 App。构建不需要 Node。`build` 写出 bundle、导入的图片和 source map。类型不在构建产物里。

## 公开模块

`@nlayer/runtime`：`signal`、`computed`、`effect`、`batch`、`untracked`、`cleanup`、`context`、`mount`、`ErrorBoundary`。

`@nlayer/ui`：`View`、`Text`、`Image`、`Scroll`、`Input`，以及 `platform`、`Keyboard`。

编辑器类型是 npm 包，版本与 `nlayer --version` 相同，包内没有 JavaScript。`@nlayer/runtime`、`@nlayer/ui`、`@nlayer/jsx-runtime`（只有类型；`jsxImportSource` 解析它；应用源码不写；没有 `@nlayer/jsx-dev-runtime`）、`@nlayer/test`（只给测试，devDependency）、`@nlayer/globals`（ambient；应用源码不导入）。`tsconfig` 的 `moduleResolution` 为 `bundler`，`typeRoots` 含 `./node_modules/@nlayer`，`types` 为 `["globals"]`。`nlayer init` 写 `package.json` 和这份 `tsconfig`，不写 `.nlayer/types`，也不调用包管理器。装类型用 `bun install`；npm 和 pnpm 也能解析同一布局。`build` / `test` / `run` 不读这些包，没有 `node_modules` 也能构建。装上的版本和 CLI 不一致时，这三条命令打一行警告，不失败。
