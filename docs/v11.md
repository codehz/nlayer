# v11

本文件是 0.11.0（v11）的产品范围和开发计划。v1 到 v10 的产品面不变，只有一条例外：`NavPage` 的头不再用 nsh / react-navigation 那套属性，改为 `UINavigationItem` 的核心。v11 不从「以后要做」取其它项。没列出的仍留在原档。永久不做、不预承诺不因 v11 改变。

## 目标

头的公开语义跟 `UINavigationItem` / `UINavigationBar`，不再跟 nsh。iOS 继续用系统 `UINavigationBar`（转场仍是 `UINavigationController`），外观是系统在该系统版本上的栏，包含 iOS 26 的液态玻璃。Android 和 web 不采样背景、不做模糊、不做折射。它们只把布局对齐 iOS 26 的栏：栏底透明，按钮浮在内容上；一个 item group 是一个悬浮控件，只有一个图标时是圆，带文字或有多项时是胶囊。不做大标题折叠，不跟滚动切 scroll-edge。

栈、模态、返回手势、`popOnBack` / `popOnSwipe` / `onBackPress` / `onDismiss` 不动。`Dialog` 没有这套头。

## 完成的标准

同一个 TSX 应用用 v11 的 CLI 在三端跑起来，并满足：

1. `NavPage` 不再接受 `headerLeft`、`headerRight`、`headerTitle`、`headerBackVisible`、`headerTransparent`、`headerStyle`。写了是不认识的属性：警告，不进树，不映射。`headerVisible` 留下。`NavHeader` 和 `setNavHeader` 从 `@nlayer/ui` 删掉。
2. 多个 `leadingItemGroups` / `trailingItemGroups`。每一组是纯按钮或自定义视图的数组。组的下标 0 靠屏幕外缘。组内下标 0 也靠外缘。
3. 返回按钮按 UIKit 拆所有权。被盖住的页写 `backButtonTitle` 和 `backButtonDisplayMode`。当前页写 `hidesBackButton` 和 `leftItemsSupplementBackButton`。没有自定义返回视图：要换掉系统返回就藏掉它，再自己放 leading group。
4. iOS 上这些属性进当前页或下一页的 `UINavigationItem`，栏的折叠、材质、scroll-edge 由系统做。Android / web 用自绘栏画出下面「自绘栏」一节，不调用系统 `Toolbar`。
5. 大标题：iOS 在有页面使用 `always` 或 `automatic` 时打开 `prefersLargeTitles`，折叠是系统的。Android / web 只在 `always` 时多画一行静态大标题，不跟滚动收起；`automatic` 和 `never` 只画普通栏。
6. `scrollEdgeAppearance` 只在 iOS 跟系统滚动切换。Android / web 忽略它，只画 `standardAppearance`。不警告。
7. 没写 appearance 时：iOS 不覆盖 `UINavigationBarAppearance`。Android / web 不铺栏底、不画分割线，按钮用下面的圆 / 胶囊。写了 `backgroundColor` 才铺栏底。写了的标题色和 tint 三端一起覆盖。`subtitle` 在 iOS 26 用系统属性；更低的 iOS 用自建 `titleView` 把标题和副标题排在一起。item group 在 iOS 16+ 用 `leadingItemGroups` / `trailingItemGroups`；iOS 15 展平后写进 `leftBarButtonItems` / `rightBarButtonItems`。
8. 旧的 gallery 和测试改到新接口。无窗口不断言像素，断言 title、subtitle、按钮、返回模式、`headerVisible`、`headerHeight`。外观在 iOS 模拟器、Android 模拟器和 web 播放器上验。

## 产品面

```tsx
<NavPage
  title="Inbox"
  subtitle="12 unread"
  titleView={<Logo />}
  largeTitleDisplayMode="always"
  backButtonTitle="Inbox"
  backButtonDisplayMode="minimal"
  hidesBackButton={false}
  leftItemsSupplementBackButton={false}
  leadingItemGroups={[
    [{ title: "Edit", onPress: edit }, <Filter />],
  ]}
  trailingItemGroups={[[{ image: icon, onPress: add }]]}
  standardAppearance={{ backgroundColor: "#fff", titleColor: "#000", tintColor: "#007AFF" }}
  scrollEdgeAppearance={{ backgroundColor: "transparent", shadowColor: "none" }}
>
  {children}
</NavPage>
```

`leadingItemGroups` / `trailingItemGroups` 的元素是组。组是数组，元素是下面两个形状之一，不能同时带 `title` / `image` 和子视图：

- 纯按钮：`title?`、`image?`（和 `Image` 的 `source` 同一份）、`onPress?`、`enabled?`（默认 true）、`tintColor?`。`title` 和 `image` 至少有一个，否则警告并丢掉这一项。
- 自定义视图：一个 nlayer 节点。视图自己画，不套按钮的 tint。按下由视图自己处理。

空组丢掉。纯按钮的 `onPress` 不是返回。返回仍走引擎 back：先 `onBackPress`，再看 `popOnBack`。

### 属性

都是响应式的。

| 属性 | 写在哪一页 | 默认 | 作用 |
| --- | --- | --- | --- |
| `title` | 当前页 | 无 | 栏标题，也是盖住它的那一页在 `default` 模式下的返回文字 |
| `subtitle` | 当前页 | 无 | 标题下的一行副标题。有应用自己的 `titleView` 时不显示 |
| `titleView` | 当前页 | 无 | 替换字符串标题和副标题。有它则不画大标题，也不画 `subtitle` |
| `largeTitleDisplayMode` | 当前页 | `"never"` | `"automatic"` / `"always"` / `"never"` |
| `backButtonTitle` | 被盖住的页 | 无 | 盖住它之后，返回按钮的文字。不设则用 `title` |
| `backButtonDisplayMode` | 被盖住的页 | `"default"` | `"default"` / `"generic"` / `"minimal"` |
| `hidesBackButton` | 当前页 | false | 藏系统返回。根页本来就没有返回 |
| `leftItemsSupplementBackButton` | 当前页 | false | true 时 leading 排在返回内侧；false 时有 leading 就替换返回（UIKit 的默认） |
| `leadingItemGroups` / `trailingItemGroups` | 当前页 | 无 | 组的数组。一组在 iOS 26 上共享一块玻璃 |
| `standardAppearance` | 当前页 | 无 | 见下 |
| `scrollEdgeAppearance` | 当前页 | 无 | 只影响 iOS |
| `headerVisible` | 当前页 | true | false 时不画栏。iOS 藏 `UINavigationBar`。内容顶 inset 回到安全区 |

`standardAppearance` / `scrollEdgeAppearance`：

- `backgroundColor?`：不写则这一项不覆盖平台默认。`"transparent"` 或 alpha 为 0：栏盖在内容上，顶 inset 含栏高（和现在的透明栏一样）。其它颜色：不透明，内容从栏下开始。
- `titleColor?`、`largeTitleColor?`、`tintColor?`。
- `shadowColor?`：不写则不覆盖。`"none"` 去掉分割线 / 系统阴影。颜色值则用这条线。

iOS 把写了的字段配进 `UINavigationBarAppearance`（不透明色用 opaque，透明用 transparent），没写的字段留给系统。Android / web 只读 `standardAppearance`。

导航其余属性不变：`animation`、`popOnSwipe`、`popOnBack`、`onBackPress`、`onDismiss`、`onInsets`、`style` / `class`。

### 自绘栏（Android / web）

对齐的是 iOS 26 液态玻璃栏的排布，不是它的材质。不读取按钮后面的像素，不做模糊、高光或折射。

栏在页面里，跟着转场走。内容行默认 44pt，上面是状态栏 inset。有 `subtitle` 且没有 `titleView` 时，内容行加高到 56pt。方向跟布局走。没写 `backgroundColor`，或它透明时：不铺栏底，没有分割线；内容从页顶排，顶 inset 含这条栏的高度。写了不透明的 `backgroundColor` 才铺满内容行，内容从栏下开始，仍然没有默认分割线。`shadowColor` 为颜色时才在内容行底部画 0.5pt 线。

标题在整栏几何中心，浮在栏底之上。没有 `subtitle` 时 17pt semibold，单行，尾部省略。有 `subtitle` 时标题和副标题作为一组垂直居中：标题 17pt semibold，副标题在其下 2pt，12pt regular，颜色是标题色的 60% 不透明度；都单行，尾部省略。这一组不进按钮的圆或胶囊。

左右按组从外向内排。组与组间距 8pt，外缘距栏边 16pt。一组是一个悬浮控件：组里只有一个图标按钮时是 44×44 的圆；组里有文字、有多项或有自定义视图时是高 44pt 的胶囊，圆角为高度的一半。组内项间距 8pt，胶囊左右各 14pt 内边距。文字 17pt regular，单行。自定义视图按自己的尺寸垂直居中，不另套一层圆。标题让开这些控件。`titleView` 居中，宽过剩余空间才被栏边裁掉；此时不画 `subtitle`。

填充是实色近似，不跟背后的内容变：浅色 `rgba(255,255,255,0.82)`，深色 `rgba(30,30,30,0.62)`。深色跟 `platform.colorScheme`。前景默认浅色黑、深色白。`tintColor` 只改这一项的前景。按下时该组填充不透明度提到 1（浅色）或 0.8（深色），不画波纹。`enabled={false}` 时这一项不接收点击，前景不透明度 0.4。

返回在非根页、当前页没有把返回替换掉时出现。返回自己算一组，不跟旁边的 leading 并进同一颗胶囊。显示模式读**下面那一页**：

- `default`：chevron 加下面那一页的 `backButtonTitle`，没有则用它的 `title`。文字空则只有圆形 chevron。有文字则是胶囊。
- `generic`：胶囊，chevron 加 `"Back"`。不本地化。iOS 的 generic 仍是系统本地化的 Back，这一处两端可以不一致。
- `minimal`：只有圆形 chevron。

chevron 仍是 v10 那条路径（`M15 18 9 12 15 6`，24 视口，线宽 2），在圆或胶囊里居中。无障碍名称是可见文字；只有 chevron 时是 `"Back"`。

`leftItemsSupplementBackButton` 为 false 且 leading 非空：不画返回，只画 leading。为 true：返回在外，leading 在内。`hidesBackButton` 为 true：不画返回。

`largeTitleDisplayMode="always"` 且没有 `titleView`：内容行里不画居中标题，下面再加一行 52pt，大标题 34pt bold，距起始边 16pt，单行尾部省略。有 `subtitle` 时，副标题接在这行大标题下面，12pt regular，标题色的 60%，距起始边 16pt。这两行没有底，算进栏高。不跟滚动收起。`automatic` 在这两端等于 `never`。

`headerVisible={false}` 不画栏。完全自己画头用这个。

### 不做

- `UISearchController`、`prompt`、`UIBarButtonSystemItem`、`subtitleView`、`attributedSubtitle`。
- 按页替换整个头组件。`setNavHeader` 不留。
- iOS 改成自绘栏。Android / web 不做液态玻璃的模糊、折射和高光，不做大标题折叠，不自动切 scroll-edge。
- 每页 `statusBar`。状态栏图标仍跟应用的 `colorScheme`。
- `Dialog` 的头。
- 旧属性的兼容映射。扁平的 `leading` / `trailing` 也不留。

### 和 v10 的差别

v10 的导航公开属性是 nsh 那套，Android / web 是一条不透明的整栏，加一个无底的返回 chevron。从这一版起属性换成 item group 和 `subtitle`。自绘栏不再铺默认栏底，一组按钮是一个浮在内容上的圆或胶囊。iOS 仍是系统栏，外观随系统；iOS 26 用 `subtitle` 和 item group，更低版本按下面的开发计划回退。

## 公开模块

仍只有 `@nlayer/runtime` 和 `@nlayer/ui`。`@nlayer/ui` 去掉 `NavHeader` 和 `setNavHeader`。`NavPage` 的属性按上面的表换。类型仍由 `gen-types` 生成。

## 开发计划

每个里程碑是一个能合的切片。改到的 crate 跑 `cargo test -p`。动到 TSX、引擎或宿主的切片还要 `nlayer test` 绿。

### M1 协议和 JS

删掉旧的 screen header 属性（`headerLeft` / `headerRight` / `headerTitle` / `headerBackVisible` / `headerTransparent` / `headerStyle`）在 core、engine、js、web 协议里的字段。换成 item group、`subtitle`、返回模式、两套 appearance、`largeTitleDisplayMode`。JS 的 `NavPage` 按所有权组包：返回标题和显示模式跟着这一页，供盖住它的页读。不认识的旧名字只警告。

无窗口模型记下这些字段和栏高（普通栏、有副标题的 56pt、透明、`always` 大标题、`headerVisible={false}`），不断言像素。

### M2 iOS

`UINavigationItem`：`title`、`largeTitleDisplayMode`、`hidesBackButton`、`leftItemsSupplementBackButton`、`backButtonTitle`、`backButtonDisplayMode`。有页需要大标题时 `prefersLargeTitles = true`。appearance 只覆盖写了的字段。`scrollEdgeAppearance` 交给系统跟滚动切换。不自绘。

`subtitle`：iOS 26 写 `navigationItem.subtitle`。iOS 15–25 不写这个属性。没有应用的 `titleView` 时，装一个自建 `titleView`，里面标题在上、副标题在下，字号和颜色跟「自绘栏」一节。有应用的 `titleView` 时只用它，`subtitle` 丢掉。iOS 26 上应用的 `titleView` 同样替换标题区，`subtitle` 不显示。

item group：运行在 iOS 16 及以上时写 `leadingItemGroups` / `trailingItemGroups`（`UIBarButtonItemGroup`）。纯按钮用 title/image，自定义视图用 `customView`。iOS 15 把组按外缘到内侧的顺序展平成 `leftBarButtonItems` / `rightBarButtonItems`，组的边界不再可见。应用的 `titleView` 在两个版本都进 `titleView`。

### M3 Android 自绘

按「自绘栏」排组合成的圆 / 胶囊、返回文字、副标题、静态大标题和 `standardAppearance`。不铺默认栏底，不做模糊。忽略 `scrollEdgeAppearance`。栏仍在每页里面，跟着转场。inset：没写不透明背景时顶 inset 含栏高。

### M4 web

删掉 `NavHeader`、`setNavHeader` 和 header 槽里的默认组件。web 的栏改由宿主按同一套自绘规则画，不再是一个可替换的 JS 组件。历史返回和 `onBack` 的路径不变。

### M5 验收

`examples/gallery` 和现有导航测试改到新属性。三端各一条：多组 leading / trailing、组内多项、补充或替换返回、三种显示模式、`subtitle`、透明 `standardAppearance`、iOS 的 scroll-edge 与大标题折叠、Android / web 的静态大标题。iOS 15 的回退（展平的 bar button items、自建 `titleView`）在模拟器上各验一次。
