# v9

本文件是 0.9.0（v9）的产品范围。v1 到 v8 的产品面不变，只有一条例外：web 的 `NavPage` 头不再由应用的 `header` 属性提供。v9 不从「以后要做」取项。没列出的仍留在原档。永久不做、不预承诺不因 v9 改变。

## 目标

v3 的 web 没有系统头。页面要自己把视图传进 `header`，而且这个节点不能同时是 `headerLeft`。三个平台的属性一样，web 却要多画一条。0.9.0 让 web 也有默认头。属性仍是那一套。iOS / Android 仍是系统栏。

## 完成的标准

同一个 TSX 应用用 v9 的 CLI 在三端跑起来，并满足：

1. web 的 `NavPage` 在 `headerVisible` 不为 `false` 时，把 `NavHeader`（或 `setNavHeader` 换上的组件）放进 `header` 槽。core 照旧量这块的高度。不透明时内容从栏下开始；`headerTransparent` 时内容从页顶排，栏盖在上面。槽和它的子节点仍读表面的顶 inset；内容的 `env(safe-area-inset-top)` 仍是 0。
2. `headerVisible={false}` 不挂这个组件。没有槽，内容的顶 inset 回到安全区。单页要完全自己画头，用这个，再把视图放进内容。
3. `NavPage` 没有 `header` 属性。传了就是不认识的属性，警告，不进树。
4. web 上 `headerLeft`、`headerRight`、`headerTitle` 是头组件的子节点，不是 `HeaderItem`。iOS / Android 不变：这三个仍进系统栏。系统栏不读 `setNavHeader`，`NavPage` 不挂 `NavHeader`。
5. 默认栏：内容行 44pt，上面是 `env(safe-area-inset-top)`；标题居中；返回是 `←`，`accessibilityLabel` 为 `"Back"`；不透明且没有 `headerStyle.backgroundColor` 时有底部分割线。浅色白底深字，深色跟 `platform.colorScheme`。`headerStyle` 覆盖背景、标题色、按钮色。`headerTransparent` 时背景透明、没有分割线，字和按钮默认白色，`headerStyle` 仍可覆盖字色和按钮色。
6. 返回按钮在非根页、`headerBackVisible` 不为 `false`、且没有 `headerLeft` 时出现。`headerTitle` 有则替换 `title`。`canGoBack` 来自栈里的下标；`NavPage` 不在栈里则为 `false`。
7. 按下返回走引擎 back，和浏览器后退同一条：先 `onBackPress`，再看 `popOnBack`，根页才落到 `BackHandler`。不调用 `nav.pop()`。不新增公开的 back API。
8. `setNavHeader(component | null)` 随时可调，已挂载的页跟着换。`null` 恢复 `NavHeader`。只影响 web。原生上这个函数什么都不做。`NavHeader` 两边都导出。原生上调用它会画出同一条栏，但系统栏不用它。
9. 栏在页面里面，跟着页面转场走，不是一条跨页不动的系统栏。
10. 无窗口测试不画这条栏，继续断言 `screen.title`、`headerVisible`、`headerHeight`。默认栏在 web 播放器测试和 `nlayer test --target web` 上验。
11. 不做：改 iOS / Android 系统栏、大标题、`headerBackTitle`、系统按钮、按页替换头组件、`Dialog` 的头。不把无窗口改成 web 的头模型。

## 产品面

### `NavHeader`

入参是 `title`、`headerLeft`、`headerRight`、`headerTitle`、`headerBackVisible`、`headerStyle`（`backgroundColor` / `color` / `tintColor`）、`headerTransparent`、`canGoBack`、`onBack`。`NavPage` 挂上组件时填 `canGoBack` 和 `onBack`。应用自己把 `NavHeader` 放进内容时，这两个可以不传：不能返回，返回键没有点击。

`setNavHeader` 的参数是接收同一份入参的函数，或 `null`。不是函数也不是 `null` 则抛 `TypeError`。

### 和 v3 的差别

v3 写的是：web 显示应用画的 `header` 槽，不排 `headerLeft` / `headerRight` / `headerTitle`。从这一版起，web 用默认组件排这三个，槽由 `NavPage` 自己挂。安全区和 `headerTransparent` 的规则不变。iOS / Android 的系统头不变。
